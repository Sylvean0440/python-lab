# 知识库网页助手

使用 Streamlit 提供网页入口，检索本地笔记后调用 DeepSeek 回答问题。

## 本机启动

在 PowerShell 中执行：

```powershell
cd C:\Users\Sylvean\Desktop\python-lab\kb-chat
python -m streamlit run app.py
```

或者在 `python-lab` 目录执行 `python -m streamlit run kb-chat/app.py`。
打开终端显示的 Local URL（通常为 `http://localhost:8501`）。保持终端运行，按 Ctrl+C 停止服务器。

本机 Python 需要安装 `streamlit`、`sentence-transformers` 和 `requests`。
应用从 `C:\Users\Sylvean\.dsh\.credentials.yaml` 读取 `DEEPSEEK_API_KEY`，从本目录 `config.json` 的 `vaultDir` 读取知识库路径。配置格式参考 `config.example.json`，目标知识库需包含有 Markdown 笔记的 `wiki` 目录。`config.json` 不提交到仓库。

## 已实现功能

- 检索笔记并回答问题。
- 同一网页会话中承接前文，并显示历史对话。
- 点击“发送”提交问题；普通页面重跑不会自动重复请求。
- 点击“清空会话”移除旧问题与回答，保留系统提示。
- 对话消息使用 SQLite 持久化；启动时读取当前会话，成功回答后成对保存用户问题与助手回答。
- 清空会话会删除当前会话的数据库记录；数据库删除失败时保留页面历史。
- 用户聊天气泡只显示原始问题；检索资料仍会发送给模型。
- 回答下显示本轮检索文件，文件名随对应回答保存在会话历史中。
- 系统提示要求回答标注实际使用的笔记来源；检索文件清单不等于实际引用证明。
- 请求设置连接/读取超时（10/60 秒），网络、HTTP 或响应格式异常时撤回本轮问题并显示错误提示。

## 历史与缓存

聊天历史在页面运行时保存在 `st.session_state`，并持久化到本地 SQLite 文件 `chat_demo_v2.db`。网页首次建立 session state 时会读取会话记录；成功回答后，用户消息和助手消息在同一事务中保存。重启恢复了此前持久化的记录。点击“清空会话”会删除当前会话的数据库记录，删除成功后再清空内存中的聊天记录并保留系统提示。数据库文件已加入仓库根目录 `.gitignore`，不应提交。

页面保留完整聊天历史；每次 API 请求包含系统提示和最近 7 条非 system 消息。请求消息仅包含 `role/content`，不发送独立的显示字段或 `sources` 字段。按消息条数选择不等于精确限制 token 数量。

当前 `CONVERSATION_ID` 固定为 `103`，仅适用于本机单会话练习；它尚未实现按用户或浏览器会话区分的多会话身份。数据库模块 `sqlite_demo.py` 提供初始化、读取、成对保存和清空函数，也包含独立练习用的 `save_message`。

首次打开页面时，资源和数据缓存尚未建立，需要加载向量模型、读取笔记并编码，因此较慢。后续缓存有效时可复用模型和编码结果。修改笔记后，缓存不一定自动更新。

模型加载使用 `local_files_only=True`，依赖本机已有的 `BAAI/bge-small-zh-v1.5` 缓存；新机器需先准备模型文件。
